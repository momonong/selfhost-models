# 0.3.0rc4：國網文件路由與固定參考版本

此版對齊新版 Codex instructions 的國網入口：在研究 repo 提出國網訓練需求，先讀研究 repo 規則，再循 `guides/service-integration.md` → [國網指南](../nchc-codex.md) → 固定樣本／必要個人筆記。已載入路由不需重貼長指示詞；獨立指示詞仍供未載入者使用。這是文件／CLI 操作介面，沒有新增自動訓練或 UI 真實提交。

研究計畫指定的參考 commit 優先，否則解析本機 HEAD；從選定 commit 讀完整已提交文件與必要引用，記完整 SHA、相對路徑及日期，同一 run 固定。dirty 草稿不冒充該 commit，唯讀查閱不 pull／切分支／覆寫修改。無本機副本時從 GitHub 正式入口定位，先解析 commit 再讀該版全文；版本或必要全文缺失只停依賴它的操作。playbook `guides-commit` 不固定外部 repo，不要求使用者手改全域版本。

`pyproject.toml`、`selfhost_models.__version__`、`uv.lock` 同為 **0.3.0rc4**；依賴、功能、UI、API／worker、schema 不變。[rc3](0.3.0rc3.md) 與歷史證據保留。未修改 agent-playbook、全域指示詞或其他研究 repo。

本輪 [驗證證據](../../evidence/2026-10-05-rc4/README.md) 包含本機 commit／dirty 與 GitHub 固定 commit 全文讀取、必要引用一致性、缺項停止 walkthrough、入口／anchor、版本／lock／wheel metadata。未變 runtime 沿用 rc3 的 **380 passed、2 skipped** 及各自原版本的離線 UI／瀏覽器證據；本輪未新跑 CPU 全套，不冒稱 rc4 GPU 或訓練驗收。

本輪提交、推送、建立 PR、正常 GitGuardian 等檢查後合併 main；無 tag／GitHub Release／images／部署／重啟／瀏覽器預覽／國網連線或工作。研究程式、job 與收據仍留在研究 repo，實際資源操作依當次授權與分段驗收。
