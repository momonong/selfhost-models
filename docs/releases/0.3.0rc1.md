# 0.3.0rc1：可分離執行端與多 worker 候選版

此版整合控制端／執行端拆分、多 worker 排程、持久維護及安全輸出清理。
它是開發候選版，不取代 `0.2.0` 或 `latest`；固定版本 tag 不覆寫。
程式／API package 版本為 `0.3.0rc1`。worker 沿用已驗證的固定 digest，來源與
OCI 版本各自保留，不把別名 tag 視為重新建置或新 GPU 驗收。

## 行為與相容性

- 控制端持有 jobs、attempts、leases、results 與排程；各 executor 持有獨立 credential、
  模型清冊、Docker/GPU、fence 與 journal。API 不掛載 Docker socket 或模型權重。
- 完整 deployment ID 匹配、urgent FIFO、有限模型親和性與 aging；單 worker 故障
  不阻塞其他相符 worker。已有 attempt 的未知工作不得跨 worker 重派。
- `maintenance pause/admissions/drain/open` 在重啟後保留；drain 等既有工作完成才卸載。
  ACK 與輸出 reader release 分開，GC 只收安全 terminal payload，永久保留去重摘要。
- Chat／SSE／jobs 與原 deployment ID 契約保留。既有 ready/models/Chat 固定對應 primary，
  不自動 fallback；新增 executors 與 all_ready 管理視圖。健康 identity probe 不再暫時清空
  同一已驗證 deployment 的 ready，身份／epoch／生命週期失配仍拒絕。

## 交付形態

| 產物 | 範圍 |
|---|---|
| API image | 新建置的非 root、locked `--no-dev --no-editable` Gateway；預設仍為 static ASGI 入口，含 modelctl 與控制端模組 |
| native controller／executor | 從固定版本原始碼 `uv sync --locked`，以獨立程序、state 與 credential 部署，依既有 Linux 程序隔離流程 |
| vLLM／Whisper | 保留 scheduler candidate 的 image digest、runtime、原 OCI source/version；不重建推論 runtime |
| static Transformers | 保留 0.2.0 固定 digest；不是 managed Whisper，也不支援影片 |

API image 不含 Docker CLI／nvidia-smi 或 executor 所需的 host mount/network 設定，
不能直接視為 GPU executor 容器。現有 Compose 是 static 部署，並非三程序 fleet 部署。
本次不新增 controller/executor Dockerfile；原生部署見 [服務監督](../scheduler-service.md)、
[拆分契約](../split-execution-plane.md) 與 [多 worker 操作](../multi-executor-operations.md)。

## 升級與回復

1. 先核對實際版本、固定 models/images、現役 owners、未確認工作及剩餘容量。維護期間
   停止新收件，保留佇列；未知工作不能當作已排空，不刪 lease/journal/ownership gate。
2. 引擎卸載、完整退出與無 model pin/lease/待清理 engine 核對後，停止相關 writers。
   以 SQLite backup 保存控制 DB，連同 executor journal、credentials、artifacts 與固定
   原始碼完整保留；升級先操作備份副本／獨立候選 state。
3. 在固定原始碼環境執行 `uv sync --locked`。離線以 `scheduler fleet-enable` 遷移，
   登錄 executor 並經認證 probe；不可用同一 GPU 的別名假裝多個獨立資源。
4. 依原生部署流程先啟 executor，再啟 controller/API；核對 ready/models、一般與 SSE
   真實呼叫和未確認 lease。此發布不自動切換既有部署，不安裝開機自啟或開放 LAN。
5. 回復前也要確認候選引擎退出並釋放 ownership。恢復原固定 artifact 與升級前 state；
   不以舊版直接開啟已遷移 DB，不同 authority 不共用去重紀錄。程序正常重啟已有驗證，
   回復舊版的完整演練、主機重開機／登出尚未驗證。

## 證據與限制

發布前完整 locked CPU 回歸：291 passed、2 Windows-only skipped，35.92 秒。
真 HTTP control＋兩 CPU executor 的並行、Landlock 拒讀、異質匹配、離線／重啟、
未知不重派、過期 fence、maintenance 與遺失 ACK 後 GC 恢復已有測試；不是多 GPU 證據。

原生 Linux 單張 RTX 4090 已完成 Qwen 文字、圖片、工具、合成影片解碼、JSON/SSE，
Whisper、模型切換、容量／取消／維護／清理及正常三程序停啟驗收。既有窗口實際
4 loads／35 generation attempts（含暖機），來源與細節見 [工程結果](../multi-executor-operations.md#本輪驗證範圍)。
本輪版本與 API 包裝更新未變更 GPU worker，有效推論程式逐 byte 核對後重用該證據；
不能稱新的 API image 已完成整組 GPU 實測，發布也不代表現役服務已切換版本。

control/executor 的 metadata slots 仍有上限且沒有 authority 自動退休／輪替；
真多主機／多 GPU、LAN、其他 OS、產品辨識／轉錄品質未驗證。合成影片成功不代表
桌球精彩度或快速攻防判斷可靠。未新增模型下載，不新增 HF 下載可用性結論。
完整主機路徑、容器資訊、憑證、DB、私人輸出與原始失敗證據保留部署端，不公開。

精確 source／image digest、包裝 smoke 與 registry 核對結果見本版發布清單（發布完成後補入）。
