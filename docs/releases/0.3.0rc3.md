## 本輪交付

- README、個人筆記與 AGENTS 提供指南入口；指南包含可貼指示詞、原生路徑定位與實驗室 `git pull --ff-only` 流程。

- SSH 22、SFTP 2222、Slurm 查詢／一次提交／未知不重送、steps／stderr／checkpoint／下載目的地與 run receipts 的操作契約；未填欄位不得直接執行。
- 2026-10-05 公開查閱 Nano5／TWCC 與 Slurm 官方文件，來源與查核範圍列於指南，當次 account／partition／wallet／環境仍須確認。
