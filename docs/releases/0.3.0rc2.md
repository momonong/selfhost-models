此版更新來源與 Python package 版本，保存可重用的個人操作筆記、固定測試與離線工具。日常入口是 [我的國網操作筆記](../nchc-personal.md)，研究程式留在各自原 repo；本機只需 SSH／SFTP 客戶端，樣本建立與 Slurm 命令在 Nano5 遠端 Bash 執行，不需要每台裝置安裝這個 repo。

- Ubuntu／macOS／Windows 共用的終端操作說明，清楚區分本機與遠端 Bash；這是操作設計，不是所有 OS 的實機驗收。

- 2026-10-03 使用者親手完成 Nano5 Job **369175**：dev／1 CPU／1 GPU／2 GiB／最多兩分鐘／no-requeue，主工作與計算 step 均 `COMPLETED 0:0`，結果 `sum=55`、`input_count=10`、`gpu_computation=false`。
- 使用者 SFTP 下載的 [65-byte JSON](../../evidence/2026-10-03-nano5-smoke/nano5-369175-result.json)，SHA256 `566774a5a7ebfeb173ee1401abdc257bdcea403bb0613fb7e0ac3d1d5722afa7`。遠端狀態由使用者貼回；main／協調者本機核對下載檔，後續移入本 repo，詳見 [證據來源](../nchc-personal.md#nano5-手動測試紀錄)。代理未連線或提交國網工作。
- 保留 `nano5-batch` 離線 UI 原型、專案／不可變工作快照、環境與資料位置 metadata、手動成果保存、契約測試與工程證據；真實提交永遠停用，UI 停止擴充。既有 [v1](../../evidence/2026-10-02-nano5-batch/README.md)／[v2](../../evidence/2026-10-02-nano5-v2/README.md) 紀錄保留原日期與當時版本。

## 相容性與證據界線

`modelctl` 與既有 API／worker 契約保持，新增的離線 CLI 使用獨立 state，沒有切換現役服務。離線工具的 additive schema、舊工作／結果保留與備份試遷移見 v2 紀錄；不要以舊版直接開啟已升級 state。

本次 Nano5 只驗證手動準備、排程、固定 CPU 計算與下載流程；申請一張 GPU 不代表執行 GPU 計算。遠端 Python 版本未記錄，研究程式、套件／SIF、大型資料傳輸、GPU 運算、其他 OS 實機及 UI 真實連線／提交均未驗收。離線 UI 的瀏覽器、遷移與 reviewer 證據沿用未變更的既有程式；reviewer 的靜態審查不冒稱第二份動態驗證。
